# ![](../../images/menu/menu_devices.png ':size=35') DEVICES

The **Devices** menu in the `Jimber SASE Platform` provides an overview and management interface for all endpoint and network devices connected to your organization’s network. It includes user devices, servers, NIACs, network controllers, and native devices.

---

- ![](../../images/menu/menu_userdevices.png ':size=20') [User Devices](./devices/userdevices/userdevices.md)  
  Endpoints such as laptops, desktops, and mobile devices assigned to users. Managed via the `Jimber SASE Client` for secure access.

- ![](../../images/menu/menu_servers.png ':size=20') [Servers](./devices/servers/servers.md)  
  Backend machines registered for secure network access. Includes Windows, Linux, Synology NAS and Raspberry Pi.

- ![](../../images/menu/menu_niacs.png ':size=20') [Network Isolation Access Clients (NIACs)](./devices/niacs/niacs.md)  
  Hardware gateways that isolate and encrypt traffic for connected devices such as printers or IP cameras.

- ![](../../images/menu/menu_networkcontrollers.png ':size=20') [Network Controllers](./devices/networkcontrollers/networkcontrollers.md)  
  Devices forwarding and controlling network traffic securely; includes cloud default and optional on-premise controllers.

- ![](../../images/menu/menu_nativedevices.png ':size=20') [Native Devices](./devices/nativedevices/nativedevices.md)  
  Devices accessible via Network Controllers with access managed through firewall rules and VLANs.
