# ![](../../images/menu/menu_security.png ':size=25') SECURITY

The **Security** menu in the `Jimber SASE Platform` offers comprehensive control over network security policies, user access, traffic management, and service exposure. It includes everything from managing user interfaces and scripts, configuring groups and traffic rules, to finely tuning service accessibility and port forwarding.

---

- ![](../../images/menu/menu_dashboard.png ':size=20') [Security Panel](./rules/security_panel/security_panel)  
  A centralized interface for users to access assigned services and monitor security status through the `Jimber SASE Client`.

- ![](../../images/menu/menu_scripts.png ':size=20') [Scripts](./rules/scripts/scripts)  
  Manage automation scripts that help customize and automate security and network tasks across your infrastructure.

- ![](../../images/menu/menu_groupconfig.png ':size=20') [Group Configuration](./rules/groupconfiguration/groupconfiguration)  
  Define and manage groups representing users, devices, or servers to control policies and permissions effectively.

- ![](../../images/menu/menu_webfiltering.png ':size=20') [Web Filtering](./rules/webfiltering/webfiltering)  
  Control and restrict web access by filtering URLs and categories to ensure safe and compliant browsing.

- ![](../../images/menu/menu_grouptraffic.png ':size=20') [Group Traffic](./rules/grouptraffic/grouptraffic)  
  Configure rules that regulate traffic flow between defined groups, enabling or restricting communication on selected ports.

- ![](../../images/menu/menu_services.png ':size=20') [Services](./rules/services/services)  
  Create and manage digital resources or applications made available to users through assigned groups and destinations.

- ![](../../images/menu/menu_attributeservices.png ':size=20') [Attribute Services](./rules/attribute_services/attribute_services)  
  Assign created services to specific groups and destinations to control accessibility within the network.

- ![](../../images/menu/menu_allowcustomports.png ':size=20') [Allow Custom Ports](./rules/customports/customports)  
  Apply fine-grained port-level rules to permit limited access between groups and servers for enhanced security.

- ![](../../images/menu/menu_portforwarding.png ':size=20') [Port Forwarding](./rules/portforwarding/portforwarding)  
  Enable external users to connect to internal services by forwarding public ports to specific internal destinations.
