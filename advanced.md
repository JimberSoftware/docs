# ADVANCED

The **Advanced** section includes powerful features and integrations for complex environments, including Active Directory support, hypervisor clusters, network controller installations, and extended platform logging. Use these tools if you're operating in enterprise setups or require deep customization and control.

---

- [Custom Configuration](./advanced/customconfiguration/customconfiguration)  
  Set advanced parameters and overrides to tailor network behavior, `Jimber SASE Client` options, or service-specific settings for your environment.

- [Active Directory](./advanced/activedirectory/activedirectory)  
  Integrate with Microsoft Active Directory to sync users and groups, and enable authentication for seamless enterprise management.

- [Microsoft Entra ID](./advanced/entraid/entraid)  
  Connect your environment to Microsoft Entra ID for centralized cloud-based identity and access control across the `Jimber SASE platform`.

- [Hypervisor Installation](./advanced/hypervisorinstallation/hypervisorinstallation.md)  
  Install and configure the `Jimber SASE Client` on your hypervisor to enable encrypted access and segmentation for virtualized environments.

- [Network Controllers Installation](./advanced/networkcontrollerssetup/SettingUpServer.md)  
  Deploy and configure standalone or Docker-based `Jimber Network Controllers` for segmenting and isolating physical networks.

- [Synology](./advanced/synology/synology.md)  
  Securely connect and manage Synology NAS systems through the `Jimber SASE Platform`, including optional factory reset and SSH setup.

- [Proxmox Cluster](./advanced/proxmox/proxmox)  
  Build a Proxmox cluster over encrypted links between hypervisors in different locations using the `Jimber SASE Platform`.

- [Docker Network Controller](./advanced/dockernetworkcontroller/dockernetworkcontroller)  
  Set up a containerized `Jimber Network Controller` for advanced routing and segmentation. Recommended for experienced users.

- [Logging](./advanced/logging/logging.md)  
  Locate and enable extended logging for troubleshooting on all supported platforms. Enable `debug.log` for more verbose output.

- [Personal Access Tokens](./advanced/personalaccesstokens/personalaccesstokens.md)  
  Generate and manage Personal Access Tokens (PATs) from the Settings page to securely authenticate and test API requests through the `Swagger` UI using your user identity.
