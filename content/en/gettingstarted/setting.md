# Important Settings

## Firewall settings

To be able to use our SASE-platform following outgoing ports must be allowed on your firewall(s): 

- 51820 UDP 
- 51820 TCP
- 443 TCP

## The minimum specifications for on-prem Network Controller
 
 - **General**:
    - 25GB hard disk

 - **For every 50 users:**
    - 2 CPU
    - 4GB RAM
