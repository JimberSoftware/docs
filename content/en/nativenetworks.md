# ![native_networks](./images/menu/menu_nativenetworks.png ':size=25') NATIVE NETWORKS

---


![native_networks](./images/menu/menu_nativenetworks.png ':size=20') &nbsp;&nbsp;&nbsp;[Networks](./nativenetworks/networks)  
 Use the Networks page to view existing networks and manage both direct and routed native networks.

![native_networks](./images/menu/menu_networkinterfaces.png ':size=20') &nbsp;&nbsp;&nbsp;[Network Interfaces](./nativenetworks/network-interfaces)   
Use the Network Interfaces page to connect physical ports and VLANs to your native networks.

![native_networks](./images/menu/menu_virtualinterfaces.png ':size=20') &nbsp;&nbsp;&nbsp;[Virtual Interfaces](./nativenetworks/virtualinterfaces.md)
 

![native_networks](./images/menu/menu_wanloadbalance.png ':size=20') &nbsp;&nbsp;&nbsp;[Wan Load Balance](./nativenetworks/wan-load-balance)  
Use the WAN Load Balance page to decide which WAN interfaces are used during normal operation and which interfaces are kept for failover.

![native_networks](./images/menu/menu_dhcpserver.png ':size=20') &nbsp;&nbsp;&nbsp;[DHCP Server](./nativenetworks/dhcp-server)   
Use the DHCP Server page to configure DHCP and DNS settings for a native network.  
  

![native_networks](./images/menu/menu_webfiltering.png ':size=20') &nbsp;&nbsp;&nbsp;[Web Filtering](./nativenetworks/web-filtering)   
Use the Web Filtering page to apply filtering policies to a selected native network.
