# ![](../../images/menu/menu_location.png ':size=25') Locations


### Create Location

To create a new location into the platform, click on the `+ Create new` button located at the upper right corner of the interface.

![create_location.png](./screenshots/create_location.png ':size=350')

The following fields are mandatory:

- Name
- Street and number
- ZIP/Postal Code
- City
- Country


### Filter Locations

You can search the list of locations using the search box at the top of the page. This helps you quickly find and manage the location you're looking for.

Use the search box to enter keywords and filter the location list.

Next to the search box, there is a filter icon ![](../../images/icons/icon_filter.png ':size=20'). When clicked, it reveals advanced filtering options where you can define additional conditions based on the following three elements:

- **Property**: A dropdown menu where you choose the field to filter on.
- **Match type**: A dropdown that allows you to select how to match the value (`equals`, `contains`, or `NOT`).
- **Value**: Enter or select the value to match, depending on the selected property.

![filter_location.png](./screenshots/filter_location.png ':size=500')

> [!TIP]
> You can refresh the list of locations by pressing the refresh icon ![](../../images/icons/icon_reload.png ':size=20') at the top of the page.

### Edit Location

Locations can be edited by clicking on the edit icon ![](../../images/icons/icon_edit.png ':size=20') in their row.

![edit_location.png](./screenshots/edit_location.png ':size=350')

All options are the same as when creating a location.

### Delete Location
Locations can be deleted by clicking on the delete icon ![](../../images/icons/icon_delete.png ':size=20') in their row.

> [!WARNING]
> This process is irreversible.

You will receive a warning before the location is permanently deleted:

![delete_location.png](./screenshots/delete_location.png ':size=400')
