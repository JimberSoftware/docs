# Paramètres importants

## Paramètres du pare-feu

Pour pouvoir utiliser notre plateforme SASE, les ports sortants suivants doivent être autorisés sur vos pare-feu :

- 51820 UDP
- 51820 TCP
- 443 TCP

## Configuration minimale requise pour le contrôleur réseau sur site

 - **Général** :
    - Disque dur de 25 Go

 - **Pour 50 utilisateurs :**
    - 2 CPU
    - 4 Go de RAM
