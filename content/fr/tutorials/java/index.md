# Tutoriel pour Java

Vous débutez en Java ? Commençons par un « HelloWorld » très simple.

Ouvrez votre éditeur de texte préféré, nommez le fichier **HelloJava.java** et copiez-collez le contenu suivant.

```java
public class HelloJava {

  public static void main(String[] args) {
     System.out.println("Hello, Java!");
  }
}
```

Vous devez d’abord disposer du SDK Java. Une fois celui-ci installé, exécutez les commandes suivantes dans l’ordre.

```bash
javac HelloJava.java
java HelloJava
```

Vous devriez maintenant voir « Hello, World » s’afficher dans la console !
