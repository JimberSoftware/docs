# Tutoriel sur le cloud

Vous découvrez le cloud ? Les plateformes cloud sont devenues très populaires ces dernières années. Il existe trois types de plateformes cloud :

- Infrastructure en tant que service (IaaS)
- Plateforme en tant que service (PaaS)
- Logiciel en tant que service (SaaS)

Mais récemment, d’autres services ont également vu le jour, comme le **conteneur en tant que service (CaaS)**.
